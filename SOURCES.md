# Sources, models, libraries and rights

## Current default path

- Music generation: original procedural synthesis code written for this assessment; no third-party audio samples, loops, recordings or pretrained music model are used.
- NumPy: https://numpy.org/
- SciPy: https://scipy.org/
- SoundFile: https://python-soundfile.readthedocs.io/
- Pyloudnorm: https://github.com/csteinmetz1/pyloudnorm
- FastAPI: https://fastapi.tiangolo.com/
- Uvicorn: https://www.uvicorn.org/

Before submission, verify the current licence terms for every dependency and record the exact installed versions (`pip freeze`). This file is not a substitute for that review.

## Limitations

The current procedural engine creates original synthesized sounds. It does not use a neural music-generation model. Any future model, API, soundfont, sample pack or dataset must be reviewed for commercial-use rights and documented here before being enabled in the default path.
